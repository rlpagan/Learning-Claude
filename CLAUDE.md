# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project status

Learning-Claude is a repository for learning and experimenting with Claude and Claude Code. It is at its very beginning: it contains only `README.md` and this file. There is no code, build system, linter or test suite yet. When one is added, update this file with the real commands and architecture instead of assuming a stack.

## Conventions

- The README and commit messages are written in Spanish; keep user-facing documentation in Spanish unless asked otherwise.
- The default branch is `main`.
- The GitHub repository name is `rlpagan/Learning-Claude` (capital L and C). Using the lowercase URL works but GitHub prints a "This repository moved" warning on push; prefer the correctly cased remote URL.
